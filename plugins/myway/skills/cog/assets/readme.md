# Cognition docs

These files record what I hold true about this system. They are my model, not a description of the code.

Format: one file per subsystem. Three sections: Believes, Decided, Unknown. One fact per line. Stable IDs (B1, D1, U1). Every Decided line has a ref. Cap 50 content lines per file.

`[pending]` marks a line an agent proposed from a commit diff. I have not reviewed it yet. Review: remove the tag, edit, or delete the line.

Commands: `/cog init` (interview), `/cog update` (compare to commits).
